# The message of the day

If your site sets a message of the day, it appears after login, in red, one
page at a time — the classic mainframe logon-notice style:

```
 ******************************************************************
 *  WELCOME TO THE CORPORATE TN3270 GATEWAY                       *
 *                                                                *
 *  Scheduled maintenance: SATURDAY 02:00-04:00 UTC.              *
 *  Report problems to the help desk (ext. 4357).                 *
 ******************************************************************



 ***
```

The `***` on the last row is the page gate: press **Enter** to continue
(through each page, if there are several) and on to the service menu. No
other key does anything here — PF3 and PA3 are deliberately inert.
